[注意] 以下转换有语义歧义，批量转换后要人工扫一眼：
  于 -> 於：於 表「在」；姓氏「于」不能转
  云 -> 雲：雲 表云；「云」作「说」时不能转（工控语境罕见）
  准 -> 準：準 表「标准」（校準 ✓）；准 表「准许」，两者并存
  台 -> 臺：臺 表台湾/台座；工作台 → 工作臺 可接受，但机台编号等场合宜保留
  后 -> 後：後 表「之后」；皇后 用后（工控语境罕见）
  复 -> 復：復 表「再、返回」（復位 ✓）；複 表「重复」（複製），不要一律转復
  并 -> 並：並 表「并且」；合併 用併
  里 -> 裡：公里 / 里 作为长度单位时应保留「里」，转成「公裡」是错的

[信息] 源字本就能编码、只是字形不同（通常无害）：
  与 -> 與、么 -> 麼、优 -> 優、体 -> 體、厂 -> 廠、听 -> 聽、周 -> 週、异 -> 異、愿 -> 願、据 -> 據、机 -> 機、杆 -> 桿、极 -> 極、构 -> 構、柜 -> 櫃、气 -> 氣、注 -> 註、洁 -> 潔、确 -> 確、离 -> 離、种 -> 種、网 -> 網、触 -> 觸、适 -> 適

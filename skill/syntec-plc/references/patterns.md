# 机床工艺模式库

拿到需求先在这里找有没有现成模式。这些模式都是在真实机床上跑过的结构，直接套用比自己推演安全。

## 记号约定

为便于阅读，下面用简写表示元件，写代码时按下表展开成 JSON：

| 简写 | 展开 |
|---|---|
| `NO("I0")` | `{"kind":"contact","norm":"NO","addr":"I0"}` |
| `NC("I0")` | `{"kind":"contact","norm":"NC","addr":"I0"}` |
| `COIL("O0")` | `{"kind":"coil","norm":"NO","addr":"O0"}` |
| `SET("A0")` | `{"kind":"coil","norm":"LATCH","addr":"A0"}` |
| `RST("A0")` | `{"kind":"coil","norm":"UNLATCH","addr":"A0"}` |
| `TMR(0,"0.1s",300)` | `{"kind":"timer","name":"TM0","precision":"0.1s","source":"#","preset":300}` |
| `TM_NO(0)` | `{"kind":"contact_t","norm":"NO","index":0}` |
| `OR([...],[...])` | `{"kind":"parallel","branches":[[...],[...]]}` |

一段之内 `[...]` 是串联。

**示例里的地址**：内部标志统一用 `A0` 起（`A` = 虚拟辅助接点，中间继电器就是它），
跨断电需要记住的**数值**用 `R193.x`。
`S0`/`S1` 这种写法在新代上**是错的**——`S` 段是核心传给 PLC 的状态（`S0`=加工中、
`S1`=暂停中），只能读不能写；`R50.x` 能跑但那是数据寄存器，不是继电器。详见 `address-map.md`。

## 1. 启保停（自保持）

最基本的自保持。按下启动 → 输出吸合 → 自身常开旁路启动按钮 → 停止常闭断开时释放。

```python
[ OR([NO("I0")], [NO("O0")]), NC("I1"), COIL("O0") ]
```

- 停止按钮用**常闭接线**（`I1` 正常时 ON，按下断开），图里用 `NC`，断线时等于按下停止 —— 这是安全侧失效。
- 用 `NC("I1")` 而不是把按钮接常开、图里用 `NC`，两者都能写，但**接线方式必须和说明文档一致**，否则现场一按就停不下来。

---

## 2. 自动/手动切换

模式信号只允许一个成立，两条路径各自汇到**同一个请求位**，不要分成两个线圈。

```python
# 模式指示
[ NO("I0"),  COIL("A10") ]            # 自动
[ NC("I0"),  COIL("A11") ]            # 手动

# 请求位 A0: 自动由定时到触发, 手动由按钮触发
[ NO("A10"), TM_NO(1), SET("A0") ]    # 自动: 间隔到
[ NO("A11"), NO("I1"), SET("A0") ]    # 手动: 按钮
```

- 手动模式下**必须屏蔽自动触发**，否则操作工在打油时又来一个自动周期。
- 切换瞬间要清掉进行中的周期：`[ NO("I0"), NO("A0"), RST("A0") ]`（切换即取消），否则手动期间会残留一个请求。

---

## 3. 一个物理输出，多个来源

物理输出 `O` 只写一个线圈。多个来源时先汇到 `A` 段标志，再单独驱动。

```python
[ NO("A0"), COIL("O0") ]                        # 唯一一处驱动泵
[ OR([NO("A0")],[NO("A12")]), COIL("O1") ]      # 打油中 或 试运行 → 指示灯
```

反例（编辑器语法检查会报「双线圈」，但**保存不拦**，实测）：

```python
[ NO("A0"), COIL("O0") ]
[ NO("A12"), COIL("O0") ]        # ❌
```

同一地址的置位/复位也各只能一处 —— 两处 `UNLATCH` 一样报「重复元件」：

```python
[ TM_NO(1), COIL("A1", "UNLATCH") ]     # ❌ 两处复位
[ NO("A4"), COIL("A1", "UNLATCH") ]     # ❌ 编辑器弹「重复元件」
# 正确: 并联成一个复位
[ OR([TM_NO(1)],[NO("A4")]), COIL("A1", "UNLATCH") ]
```

## 4. 报警锁存 + 复位

> **先想清楚这类报警该不该锁。** 锁存不是默认要求：需要「查完再复位」的（过载、超程、
> 刀库错位）才锁；温度、压力、液位这类过程量常常要求故障消失就自动恢复，
> 锁了反而要操作工多按一次。**按设备要求定，别按习惯定。**

故障一出现就锁住，**只有「按了复位」且「故障源真的消失」才清得掉**。

```python
# 置位: 故障出现即锁存
[ NO("I2"),  SET("A2") ]              # 油位低
[ NC("I4"),  SET("A3") ]              # 热继断开(常闭接线, 断开=过载)
[ TM_NO(2),  SET("A1") ]              # 压力建立超时

# 汇总
[ OR([NO("A1")],[NO("A2")],[NO("A3")]), COIL("A4") ]

# 复位: 按 I5 且 故障源已消失
[ NO("I5"), NC("I2"), NO("I4"), RST("A2") ]
[ NO("I5"), NC("I2"), NO("I4"), RST("A3") ]
[ NO("I5"), NC("I2"), NO("I4"), RST("A1") ]
```

**复位条件里必须串上故障源状态**。只写 `[NO("I5"), RST("A2")]` 的话，电机还热着操作工一按复位就又能启动——等于把保护拆了。

报警输出：

```python
[ NO("A2"), COIL("O2") ]
[ NO("A1"), COIL("O3") ]
[ NO("A3"), COIL("O4") ]
[ NC("A4"), COIL("O5") ]              # 就绪灯
```

## 5. 单次动作周期（点动 → 一个完整周期）

按一下就执行完整周期，**不是按住才动**。避免操作工按久了过量。

```python
[ NO("I1"), SET("A0") ]               # 按钮按下置位请求(SET 只需电平, 按多久都只置一次)
[ TM_NO(0), RST("A0") ]               # 时长到 → 结束
[ NO("A4"), RST("A0") ]               # 故障 → 立即结束
[ NC("I6"), RST("A0") ]               # 停止 → 取消
[ NO("A0"), TMR(0,"0.1s",300) ]       # 请求期间计时 30s
[ NO("A0"), COIL("O0") ]              # 驱动
```

- 用 `SET` 而不是 `COIL("A0")`，按钮松开后请求仍在——**这一条就替代了上升沿**，
  不需要再给按钮加脉冲。
- 三个出口缺一不可：正常结束、故障中止、人工取消。少了「人工取消」，一旦卡住只能断电。
- 换成正缘脉冲 `RP` 再 `COIL` 也能做，但要注意**每个扫描周期只通一拍**，
  后面的定时器得靠保持位，加一层反而更容易错；按钮长按出错风险的场合才值得这么做。

## 6. 定时循环（间隔 + 时长）

```python
[ NC("A0"), TMR(1,"1s",1800) ]        # 不在打油时, 累计间隔
[ NO("A0"), TMR(0,"0.1s",300) ]       # 打油中, 累计时长
[ NO("A4"), RST("A0") ]               # 故障时清掉
[ NC("A4"), NO("A11"), TM_NO(1), SET("A0") ]   # 手动模式且间隔到 → 起
```

注意：定时器的输入条件断开时计时自动清零，所以「间隔」那个定时器要串 `NC("A0")`——打油期间不计间隔，否则间隔会算进打油时间。

### 6.1 时长和间隔要做成参数，不要写死

`TMR(1,"1s",1800)` 里的 1800 是**死数**：换台机床、客户想改打油频率，都得改程序、重新生成、
重新验证。新代给了专门的通道 —— `R81`~`R100` 对应系统参数 `3401`~`3420`，操作员在参数画面改，
程序只读：

```python
# 参数 3401 = 打油时长 (0.1s)，参数 3402 = 打油间隔 (1s)
[ NC("A0"), TMR(1,"1s","R82") ]       # 间隔, 预设取 R82
[ NO("A0"), TMR(0,"0.1s","R81") ]     # 时长, 预设取 R81
```

定时器结构体里就是 `source:"R"`（`preset` 填寄存器号，写 `"R81"` 或 `81` 都认）：

```json
{"kind":"timer","name":"TM0","precision":"0.1s","source":"R","preset":"R81"}
```

配套三件事，少一件就会在现场出问题：

1. **给下限保护。** 没设过的参数是 0：时长为 0 泵一闪而过，间隔为 0 变成连续打油。
   `[ CMP("GTK","#1","R81"), ... ]`（即 `#1 > R81`，等价于 `R81 < 1`）报警并禁止启动。
2. **参数无效不要锁存。** 改对就该自动恢复，不必让操作工再按一次复位。
3. **注释写清单位。** `R81` 是 0.1 秒、`R82` 是 1 秒 —— 不写，下一个人一定填错。

`R81`~`R100` 是单向只读（参数 → 阶梯图），写它会被点名（提示级，拦不住）；也别把参数塞
`R50`~`R80`，那里掉电不保持，断电后参数回零。

## 7. 瞬变量屏蔽（压力、流量、液位波动）

定量泵打油时分配器换向会让压力瞬时掉一下。全程监视 → 正常打油也报压力异常。

解法：**建立起一次就置一个「已建立」标志，本次周期不再管**。

```python
# 打油中 且 已有压力 → 记下"本次已建立过"
[ NO("A0"), NO("I3"), SET("A6") ]
# 打油中 但 从未建立过压力 → 计时
[ NO("A0"), NC("A6"), NC("I3"), TMR(2,"0.1s",100) ]
# 超时 → 报警
[ TM_NO(2), SET("A1") ]
# 周期结束 → 清标志, 为下次做准备
[ TM_NO(0), RST("A6") ]
[ NO("A4"), RST("A6") ]
```

同类问题：液位开关在晃动时抖动、流量计脉冲丢失。都需要「确认窗口 + 标志位」，不要直接用瞬时值做保护。

## 8. 顺序启动 / 顺序停止

停机顺序和启动顺序相反，是机床的基本要求（先停主轴再停冷却，否则工件烧伤）。

```python
# 启动: 冷却 → 延时 → 允许主轴
[ NO("I0"), COIL("O20") ]                        # 冷却泵
[ NO("O20"), TMR(3,"0.1s",20) ]                  # 冷却建立 2s
[ TM_NO(3), NO("I1"), COIL("A7") ]                 # 允许主轴信号

# 停止: 主轴先停 → 延时 → 冷却停
[ NC("A7"), NC("O21"), TMR(4,"1s",5) ]             # 主轴已停 5s
[ NO("O21"), TMR(4,"1s",0) ]
[ TM_NO(4), NC("A7"), RST("O20") ]
```

- 顺序停止用「前级已停 + 延时」串起来，不要用同一个按钮去同时断两个输出。

## 9. 互锁（正反转、两工位互斥）

```python
# 正转: 串反转输出的常闭
[ NO("I0"), NC("I1"), NC("O11"), COIL("O10") ]
# 反转: 串正转输出的常闭
[ NO("I1"), NC("I0"), NC("O10"), COIL("O11") ]
```

- **互锁要用对方输出的常闭**，不要用对方按钮的常闭——按钮松开就失效了。
- 电气上还应有硬件互锁（接触器常闭互串），软件互锁不能替代。说明文档里要写这句。

## 10. 计数到位动作

```python
[ NO("I3"), {"kind":"counter","name":"CT1","direction":"UP","source":"#","preset":50} ]
[ {"kind":"contact_c","norm":"NO","index":1}, COIL("O30") ]
[ NO("I5"), {"kind":"counter","name":"CT1","direction":"RESET","source":"#","preset":0} ]
```

- 计数预设值工具卡在 255 —— 这是保守做法，编辑器真实上限**未验证**（见 `element-grammar.md` §3）。
- 需要复位时用 `RESET` 方向的同一编号，不要新建计数器。
- 计数脉冲最好用 `RP` 正缘线圈产生，避免信号保持期间连续计数。

## 11. 模拟量阈值 + 回差

单一阈值会在临界点反复通断。

```python
# 低于下限 → 置位      #80 > R300，即 R300 < 80
[ {"kind":"compare","op":"GTK","A":"#80","B":"R300"}, SET("A8") ]
# 高于上限 → 复位（回差 20）   #100 < R300，即 R300 > 100
[ {"kind":"compare","op":"LTK","A":"#100","B":"R300"}, RST("A8") ]
```

- 上下限之间要留回差，回差大小按信号噪声定。
- 没有 `GE`/`LE` 编码，把边界挪 1 个单位来等效（`X >= 80` 写 `R300 > 79`）。
- 带 `K` 的比较块**常数在 A、寄存器在 B**，方向是「左 op 右」——写成 `LTK(R300, #80)`
  会被工具拒绝（编辑器里会变成 `#83 == R0` 那种恒假条件）。

## 12. 上电初始化

**新代是否有「首次扫描」专用标志位，本项目未验证。** 不要凭猜测写。

可行的保守做法：用一个 `A` 段保持寄存器做「已初始化」标记，上电后第一次扫到未初始化就执行初始化并置标记。具体 `A` 地址与掉电保持特性必须查手册确认，**并在说明文档里标注「此段依赖手册确认，未在真机验证」**。

如果需求只是「上电时所有输出为断开」，通常靠输出默认状态即可，不必写初始化逻辑。

## 组合示例：完整的间歇润滑（真实程序结构）

把上面几个模式拼起来就是一台机床的润滑站。完整实现见项目仓库 `examples/`：

```
R1-R2   自动/手动模式指示
R3-R5   打油请求 A0 的三入口两出口收敛
R6-R8   并联: 自动间隔到 / 手动按钮 → 置位 A0
R9      时长计时 TM0
R10     压力监视 TM2（带 A6 屏蔽）
R11-R13 三种故障锁存
R14     故障汇总 + 就绪
R15-R21 输出驱动(每地址唯一线圈)
R22     END
```

设计要点：**所有「谁能启动」都能在置位行找到，所有「谁能停止」都能在复位行找到**。一眼能数清的入口出口，比一堆自保持回路好维护。

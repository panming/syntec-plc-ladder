# 安装说明（给不碰命令行的人）

这份文档教你把「新代梯形图工具」装进 WorkBuddy。全程不用打字，只有两处要复制粘贴。

装完以后，你可以直接对 WorkBuddy 说人话，比如：

> 帮我写一个液压站启停的梯形图，开机默认停泵，按按钮启动后自锁，过载和急停都要停泵。

它会给你生成一个 `.lad` 文件，用新代 PLC 编辑器打开就能看。

---

## 装之前，先做两件事

**1. 关掉 WorkBuddy。**
不是点右上角的 ❌——那个只是关窗口，程序还在后台跑。要**右键点右下角托盘里的小图标 → 退出**。
（如果找不到托盘图标，先点托盘左边的 `^` 展开。）

**2. 确认手上有两样东西：**

| 东西 | 长什么样 | 从哪来 |
|---|---|---|
| 安装包 | 一个 `.zip` 压缩包，名字里有 `安装包` | 朋友发给你 |
| Python | 一个能装软件的电脑 | 下一步装，装过一次就不用再装 |

---

## 第 1 步：装 Python

**先看装没装过。** 按键盘 `Win + R`，输入 `cmd`，回车，会出现一个黑窗口。在里面输入：

```
python --version
```

- 看到 `Python 3.12.1` 这种 → **已经装了，跳到第 2 步**
- 看到「不是内部或外部命令」→ 接着往下看
- **弹出了微软商店** → 这也是没装，把商店关掉，接着往下看

**装的方法：**

1. 打开 https://www.python.org/downloads/
2. 点页面上那个黄色的 **Download Python 3.x.x** 按钮
3. 双击下载好的安装包
4. **第一屏最下面有一行 `Add python.exe to PATH`，前面那个框一定要打勾**
   （这一步漏了，后面全部白费，而且报错看不懂）
5. 点 `Install Now`，等它走完，点 Close

装完再回去 `cmd` 里输一次 `python --version`，能看到版本号就成了。

---

## 第 2 步：把安装包解压到固定位置

**右键安装包 → 解压到当前文件夹**（或者用 7-Zip / Bandizip 的「解压到」）。

然后**把解压出来的整个文件夹挪到 `C:\Tools\` 下面**（没有 `Tools` 就自己新建一个）。

为什么不能放桌面或下载文件夹：这两个地方经常被清理软件扫，或者你自己顺手删了。
工具文件一旦被删，WorkBuddy 那边就找不到它，会报一堆错。放 `C:\Tools\` 就不容易误伤。

放好以后，文件夹里应该是这样：

```
C:\Tools\syntec-安装包\
├── 双击安装.bat            ← 一会儿双击这个
├── setup.py
├── 安装说明.md             ← 你正在看的这份
├── syntec-ladder-mcp-standalone.py
└── skill\
    └── syntec-plc\         ← 里面的 SKILL.md 等文件不要动
```

---

## 第 3 步：双击 `双击安装.bat`

**如果弹出「Windows 已保护你的电脑」**：点左边的 `更多信息` → 点 `仍要运行`。
（这是 SmartScreen 对来历不明文件的例行提醒，不是报毒。）

双击之后会出现一个黑窗口，它会自己跑四步。**正常的话你会看到这样的输出**：

```
--- 第 1/4 步：检查 Python ---
[OK] Python 3.12.1

--- 第 2/4 步：找到安装文件并试跑 ---
[OK] 工具：C:\Tools\syntec-安装包\syntec-ladder-mcp-standalone.py
[OK] 技能包：C:\Tools\syntec-安装包\skill\syntec-plc
[OK] 工具自检通过：[PASS] 单文件版可用, 共 13 个工具

--- 第 3/4 步：安装技能包 ---
[OK] 技能包已装到 C:\Users\你的名字\.workbuddy\skills\syntec-plc（12 个文件）

--- 第 4/4 步：登记 MCP 工具 ---
[OK] 已写入 C:\Users\你的名字\.workbuddy\mcp.json
```

**只要四步都是 `[OK]`，就装成功了。** 看到 `[!!]` 就翻到最后一节《出问题看这里》。

窗口最后会停在「按任意键关闭」——按任意键关掉就行。

> 重装、升级都直接用这个文件，重复运行是安全的。旧的技能包会自动备份成
> `syntec-plc.bak-日期时间`，旧的 MCP 配置会备份成 `mcp.json.bak-日期时间`。

---

## 第 4 步：打开 WorkBuddy，点一次「信任」

这一条**最容易漏**：配置写进去了，但 WorkBuddy 出于安全不会自动启用新工具。

1. 打开 WorkBuddy
2. 找到「连接器」或「MCP」那一栏（在左侧栏的加号菜单，或设置里）
3. 切到「**自定义**」标签
4. 列表里应该有 **syntec-ladder**，点它右边的「**信任**」或「**启用**」

点完那个开关变成开启状态，就对了。

---

## 第 5 步：验收——发一句话试试

新建一个对话，把下面这段整个发给它：

```
用 syntec 技能帮我写一个液压站启停的梯形图。
要求：开机默认停泵，按面板按钮启动后自锁，过载和急停都要停泵。
```

**装对了的样子**：它会说「我先确认一下工具」，然后去调用 `explain_format`、`add_rung`、
`validate` 这类工具（你能看到一条条工具调用记录），最后给你一个 `.lad` 文件。

**没装对的样子**：

| 现象 | 说明 |
|---|---|
| 它说「我没有这些工具 / 我无法生成 .lad 文件」 | MCP 没连上，回第 4 步看「信任」点了没 |
| 它一直追问你要格式、要范例，写得很外行 | 工具在，但技能包没装，回第 3 步重跑 |
| 它说「已生成」但打开是错的 | 这个不会发生。真的发生了，把文件发给朋友 |

---

## 装好之后能干什么

直接说人话就行，不用记命令：

- 「看一下这个 cnc.lad，第 30 行附近那段报警是干嘛的」——把文件拖进对话
- 「刀库换刀时，刀具没到位就卡住了，帮我加个超时报警」
- 「排屑机正转自保持、反转点动，帮我按这个写一段」
- 「这个程序的注释是简体，帮我转成编辑器能显示的繁体」
- 「检查一下这个程序有没有同一个输出点被两处驱动」

它的能力边界：**它只生成文件，不直接连机床**。生成的 `.lad` 必须用新代 PLC 编辑器
打开核对，再拷到控制器里。这条不要省——文件格式没有校验和，错了编辑器不报错，只显示一张错的图。

## 出问题看这里

先看黑窗口里第一行 `[!!]` 说什么，再对下面这张表。

| 黑窗口里看到 | 原因 | 怎么办 |
|---|---|---|
| 窗口一闪就没了，什么都没显示 | Python 没装好，或 `py` 找不到 | 按 `Win+R` 输 `cmd`，把 `双击安装.bat` **拖进黑窗口**再回车，就能看到报错 |
| `[!!] 这台电脑上没有可用的 Python` | 没装，或装的时候没勾 PATH | 按它提示的做，**重点是勾 `Add python.exe to PATH`** |
| `[!!] Python 版本 3.x 太旧` | 版本低于 3.8 | 装个新版，旧的可以留着 |
| `[!!] 没找到 syntec-ladder-mcp-standalone.py` | 解压不完整，或被杀毒软件删了 | 重新解压一次；还不行就关掉杀软再解压，然后把那个文件夹加进白名单 |
| `[!!] 没找到 skill/syntec-plc/ 目录` | 同上，`skill` 文件夹被删了 | 同上 |
| `[!!] 自检没通过` | 杀软拦截，或 Python 环境坏了 | 先把整个文件夹加杀软白名单再跑；还不行换个 Python 版本 |
| 第 4 步说「不是合法的 JSON，不敢动它」 | 你原来的 `mcp.json` 被别的软件写坏了 | 别自己改。把这一行后面的路径发给朋友，让他帮你看 |
| 装完了但 AI 还是说没工具 | 没重启 WorkBuddy，或没点「信任」 | 完全退出（托盘右键退出）再打开；然后回第 4 步点信任 |
| 装完了 AI 能调工具，但写得很外行 | 技能包没装进对的地方 | 看 `C:\Users\你的名字\.workbuddy\skills\syntec-plc\SKILL.md` 在不在；不在就重跑第 3 步 |
| 中文显示成乱码或问号 | 黑窗口的编码问题，**不影响安装结果** | 忽略。真在意的话，看第 3 步的四个 `[OK]` 齐了就行 |

---

## 想卸载 / 想换台电脑

**卸载**（两步，都是删文件夹）：

1. 删掉 `C:\Users\你的名字\.workbuddy\skills\syntec-plc`
2. 用记事本打开 `C:\Users\你的名字\.workbuddy\mcp.json`，把 `"syntec-ladder": { ... }` 这**一整段**
   删掉（注意别删到后面那个逗号之外的括号）。改坏了就把旁边的
   `mcp.json.bak-日期时间` 改名回 `mcp.json`。

**换电脑**：把 `C:\Tools\syntec-安装包\` 整个文件夹拷过去，从第 1 步开始走一遍。

---

## 它对你的电脑做了什么（一句一事的交代）

- 在 `C:\Users\你的名字\.workbuddy\skills\` 下放了一份技能包（十几个文本文件）
- 在 `C:\Users\你的名字\.workbuddy\mcp.json` 里加了一段配置，指向那个 `.py` 文件
- 改动前都留了备份

**不联网、不开端口、不在后台常驻。** 它只是被 WorkBuddy 在需要时调用一次，读写你指定的
`.lad` 文件，然后结束。
